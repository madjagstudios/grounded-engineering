# Security

Grounded Engineering is a documentation repository with local validation tooling. It does not operate a hosted service, process user credentials, or receive production data.

Please do not include secrets, private repository content, personal data, or confidential vendor material in issues or pull requests. For a suspected security problem in the validation tooling or repository automation, use the repository's private security-reporting channel when available. If that channel is not enabled, contact the maintainers through the repository's GitHub security settings before public disclosure.

Security reports should include the affected file or command, a minimal reproduction, and the impact. Do not include live credentials or sensitive data in the report.
